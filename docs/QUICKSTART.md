# Retired legacy quickstart

The inherited Kairo Phantom installation and ghost-writing instructions at this
path are retired. They are not the launch contract for the current Axiom-Grid
engineering preview. Do not use old installer links, package commands, default
model downloads or application-injection instructions as a supported setup path.
Git history retains the former document for reference, not current deployment.

Use the [focused engineering-preview quickstart](../QUICKSTART.md).

Current scope: visible explicit input, authenticated loopback runtime, review and
manual copy on authorized devices and permitted tasks. No silent installation,
ambient capture or automatic application typing. Models require independent
approval and explicit provisioning; reported identity is not backend attestation.

Native target-device, real-model, disconnected operation, installer lifecycle and
production qualification remain separate gates. Bundling remains disabled. See
[device qualification](DEVICE_QUALIFICATION.md) and
[release qualification](RELEASE_QUALIFICATION.md).
