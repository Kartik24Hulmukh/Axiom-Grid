   bearer token or retries consume worker slots. Refuse redirects, enforce secure
   destination configuration and test actual loopback fault cascades. Live model
   identity, spend limits and quality are separate credential-gated validation.

   or zero-egress proofs. Pin keys independently, retain checkpoints, test tamper
   and concurrent writers, document replay/source-honesty limits, and recruit real
