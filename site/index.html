What Axiom-Grid Does

📄 READ + SUGGEST ONLY

Axiom-Grid reads your documents and suggests answers. It never writes to or drives your source applications. Every suggestion requires explicit human confirmation.

🔒 Offline-First

Local document preview and receipt verification do not require a provider. Optional model services and telemetry can use the network; sealed runtime checks are not an OS-wide zero-egress guarantee.

✍️ Signed Receipts

Explicit trace exports produce Ed25519-signed observations in a linear SHA-256 hash chain. Verify against a pinned public key and retained checkpoint. Export adapters are not live every-action instrumentation.

🛡️ Injection Defense

106 injection patterns loaded (measured; CI regression floor: ≥56). Committed attack corpus: 25/25 blocked, 0/15 false positives on benign inputs — reproducible with pytest tests/security/test_injection_suite.py -q -s.

Reproduce the Receipt Demo

Synthetic signed sample, offline verification. This is not a recorded human test or live OpenBot integration.

1

Inspect the sample

python -m json.tool examples/receipts/sample.json

The sample contains synthetic observations, not captured customer activity.

2

Pin the signer and checkpoint

python scripts/axiom_receipts.py verify examples/receipts/sample.json \
  --public-key examples/receipts/sample-public.pem \
  --checkpoint examples/receipts/sample-checkpoint.json

For real exports, provision your own key and obtain the public key out of band. Do not trust a replacement key embedded in an export.

3

Exercise rejection cases

python -m pytest kernel/tests/test_agent_receipts.py -q

Tests cover tampering, pinned trust and concurrent exports. A valid signature is not proof of execution, completeness, citation truth or legal compliance.

Separate legal-redline workflow

python -m kairo.cli redline fixtures/demo/sample_nda.docx fixtures/demo/nda_playbook.json --out demo_output

This creates new local outputs under its own manifest format. It does not perform a desktop write or automatically emit the agent receipt format. Runtime sealed checks are separate from OS-wide egress enforcement.

What Axiom-Grid Does NOT Do

  • Write to or drive source applications (Word, Excel, desktop) — v1 is READ + SUGGEST ONLY
  • Act as a multi-domain expert swarm or router
  • Operate as a collaborative/cloud-by-default layer
  • Auto-apply any suggestion without explicit human confirmation
  • Treat a generated bounding box, signature or retained text preview as independent proof of every citation
