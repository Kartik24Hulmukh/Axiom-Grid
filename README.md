# Axiom-Grid

A focused, local-first writing copilot derived from Kairo-Phantom. **Engineering preview — not a production release.**

The initial wedge is user-reviewed text assistance in supported desktop editors. Universal app automation, enterprise certification, zero-egress attestation and performance/traction claims are **not verified**.

## Repository boundary

Imported from `Kartik24Hulmukh/Kairo-Phantom` at `8975743`. Upstream is not modified. MIT license and source history are retained. Rust crate names remain compatible during extraction.

Inherited release workflows and launch documents are archived under `docs/inherited/`; they are not Axiom-Grid launch evidence. The new focused CI is independent of the inherited release automation.
